# Tree Testing

Tree testing involves replicating a website navigation (existing or proposed) in a link "tree". Recruited participants are then set tasks to find specific content or information within the link tree. This provides data on how easy specific content is to find within the navigational structure.

## When to reach for it

Tree testing is similar to card sorting in that it provides insight into the navigational structure of a website.
It can be used to gather initial data into where the main issues are within an existing navigational structure (as identified via other research methods), and it can also be used as a validation technique to validate changes/improvements.

## Strengths

Tree testing is a relatively unique research method due to its focused nature (specifically focused on website content structure).
Tree testing provides insight into how easy content is to find within an existing or proposed navigational structure.
Tree testing can be done on existing structures to identify issues and opportunities or on proposed structures to validate changes.
Tools like OptimalWorkshop make tree testing relatively quick and easy to set up and run.

## Limits

Data analysis can be difficult/time intensive. The data provided by tools like OptimalWorkshop is extensive and although can be very insightful, it takes some understanding of the data to accurately interpret it.

## Practical considerations

Practical considerations

### Sample Size
Tree testing is primarily a quantitative method, and as such the sample size should be treated accordingly. There isn't a one-size-fits all number; instead the right number is based on the level of precision needed. Most tree tests have between 50-150 participants.
